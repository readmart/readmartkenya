# **READMART FOUNDER DASHBOARD: USER GUIDE**

## **1. Introduction**
Welcome to the ReadMart Founder Dashboard. This guide is designed to help Founders and Administrators manage the platform's ecosystem, from processing orders to overseeing partner relationships.

---

## **2. Getting Started**

### **2.1 Accessing the Dashboard**
- **URL**: `https://readmart.com/founder` (or local environment)
- **Requirements**: You must be logged in with an account assigned the **'admin'** or **'founder'** role.
- **Login**: Use your official ReadMart credentials via the standard login portal.

### **2.2 Dashboard Overview**
Upon logging in, you will see a sidebar with 19 specialized modules.
- **Global Sync**: Use the button at the bottom of the sidebar to manually refresh all data across the dashboard.
- **Realtime Updates**: The dashboard automatically updates in realtime for orders, inquiries, and user status changes.

---

## **3. Core Module Guides**

### **3.1 Managing Orders & Fulfillment**
The **Orders** module is the heart of the logistics workflow.
- **Filtering**: View orders by status (Pending, Paid, Processing, Shipped, Delivered).
- **Processing**: When an order is paid, move it to 'Processing' to signal the warehouse.
- **Fulfillment**: Once dispatched, update the status to 'Shipped' and provide tracking info if applicable.
- **Realtime Alerts**: New orders will trigger a notification in the dashboard.

### **3.2 User Management**
The **Users** module allows you to oversee all platform participants.
- **Roles**: View whether a user is a Customer, Author, or Admin.
- **Account Control**: Use the 'Active/Inactive' toggle to manage platform access for specific users.
- **PII Access**: Founders have full access to user emails and phone numbers for support purposes.

### **3.3 Content & CMS**
- **Banners**: Manage the sliding promotional images on the homepage. Ensure images are high-resolution (1920x600 recommended).
- **Author of the Day**: Select an approved author to feature on the main landing page.
- **Agreements**: Upload and manage legal documents for partners and authors.

### **3.4 Marketing & Engagement**
- **Promos**: Create discount codes. You can set usage limits, expiration dates, and percentage/fixed discounts.
- **Newsletter**: Manage your subscriber base. You can export the list or send custom announcements directly from the **Communications** tab.
- **Clubs & Events**: Oversee the digital community by creating and managing book clubs and upcoming literary events.

---

## **4. Financials & Payouts**

### **4.1 Payouts Workflow**
- **Overview**: View all pending commissions for authors and logistics partners.
- **Disbursement**: Use the **'Disburse Payouts'** button to trigger the payment engine for all pending records.
- **Security**: This action requires a final confirmation as it initiates actual financial transfers.

---

## **5. Troubleshooting & FAQ**

### **5.1 Common Issues**
- **"Failed to Fetch Metrics"**: This usually occurs due to a temporary network issue or a schema update. Try clicking **'Global Sync'**.
- **Payment Not Reflecting**: If a customer claims to have paid but the order is 'Pending', use the **'Check Status'** button within the order details to manually query the payment gateway.
- **Image Upload Failed**: Ensure the file size is under 5MB and the format is JPG, PNG, or WebP.

### **5.2 FAQ**
- **Q: Can I delete an order?**
  - A: Orders can be 'Cancelled' but not deleted from the database to maintain financial audit integrity.
- **Q: How do I promote a user to Admin?**
  - A: For security reasons, role upgrades must be performed via the **'Identity'** tab or by a Founder-level account.
